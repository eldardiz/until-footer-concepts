# UNTIL footer concepts

Two footer directions for [until.co.uk](https://www.until.co.uk), built on the same link structure as the new mega nav.

- **A · Ink**: dark rounded panel, big call to action, scrolling practitioner pills, faded UNTIL wordmark. Open with `#a`.
- **C · Big type**: light editorial footer, giant Tungsten practitioner ticker, big contact link, ruled locations row, back to top. Open with `#c`.

Switch between them with the toggle at the top of the page.

Fonts: DIN 2014 (UNTIL's Adobe Fonts kit) and Tungsten Semibold (UNTIL's Webflow asset). Icons: [Lucide](https://lucide.dev) (ISC).
Class names follow Client-First (`footer-ink_`, `footer-type_`, shared `footer_`) for the Webflow build.

In this hosted copy, footer links point to the live until.co.uk pages.
