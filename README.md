# UNTIL footer: Ink

The chosen footer direction for [until.co.uk](https://www.until.co.uk), in two themes, built on the same link structure as the new mega nav.

- **Dark** (default): ink panel, white call to action, translucent practitioner pills, faded UNTIL wordmark. Open with `#dark`.
- **Light**: the same footer on a soft grey panel, UNTIL blue call to action, white practitioner pills. Open with `#light`.

Switch between them with the toggle at the top of the page.

Fonts: DIN 2014 (UNTIL's Adobe Fonts kit) and Tungsten Semibold (UNTIL's Webflow asset). Icons: [Lucide](https://lucide.dev) (ISC).
One component for Webflow: Client-First classes `footer-ink_` (plus shared `footer_`), light theme = combo class `is-light`, colours driven by `--fi-*` tokens.

In this hosted copy, footer links point to the live until.co.uk pages.
